1. Qué datos procesamos

UX Tools procesa únicamente los datos que tú introduces de forma activa al usar las herramientas de la suite. Estos datos son:

  • Sesiones de Benchmark: nombres de productos, scores por dimensión, nombre del analista, fecha.
  • Documentos UXFlow: criterios de aceptación, nombre de flujos, notas.
  • Dimensiones y templates personalizados: los que configures en el panel Admin.
  • Stamp de onboarding: qué módulos has visitado (solo IDs de módulo, sin PII).
  • Passkey (si la configuras): el identificador público (rawId) de tu credencial WebAuthn. Nunca la clave privada.
🔒 No recopilamos nombres reales, emails, contraseñas, datos de facturación, IPs ni ningún otro dato de identificación personal.
💾

2. Cómo y dónde se almacenan

Todos los datos se guardan en el localStorage de tu propio navegador, en tu dispositivo local. No existe ningún servidor propio ni base de datos en la nube que almacene tu información.

Las claves de almacenamiento utilizadas son:

  • uxbenchmark-state — sesiones del Benchmark
  • uxflow-historial — documentos UXFlow
  • uxbenchmark-dimensiones — dimensiones personalizadas
  • uxflow-templates — templates de criterios
  • uxtools-onboard-stamps — registro de primeras visitas
  • vn-passkey-id — identificador público de passkey (si la usas)
📍 Los datos nunca salen de tu dispositivo hacia ningún servidor externo. GitHub Pages solo sirve los archivos estáticos de la aplicación.
🎛

3. Tu control sobre los datos

Tienes control total sobre tus datos en todo momento:

  • Exportar: desde el panel Admin → Exportar puedes descargar un JSON completo o un CSV de tus sesiones de Benchmark.
  • Eliminar todo: en Admin → Seguridad → "Eliminar todos mis datos" borras permanentemente todo lo almacenado en este dominio.
  • Eliminar manualmente: desde las DevTools de tu navegador puedes inspeccionar y eliminar cualquier clave de localStorage.
  • Retención: los datos persisten hasta que los borres explícitamente, limpies el almacenamiento del navegador o uses el modo incógnito.
🔑

4. Passkey — autenticación sin servidor

Si eliges configurar una passkey en Admin → Seguridad, se utiliza la API estándar WebAuthn del navegador (Web Authentication API). Su funcionamiento es:

  • La clave privada criptográfica nunca sale de tu dispositivo; la gestiona el autenticador de plataforma (Face ID, Windows Hello, huella dactilar, etc.).
  • Solo guardamos en localStorage el rawId (identificador público de la credencial), que es un valor no sensible.
  • No enviamos ningún dato a ningún servidor para verificar la passkey. La verificación es completamente local.
  • La passkey protege acciones destructivas (como borrar todos tus datos) para añadir una capa extra de confirmación en el dispositivo.
  • Puedes eliminar la passkey desde Admin → Seguridad en cualquier momento.
🛡 La passkey de UX Tools es un mecanismo de confirmación local, no de autenticación remota. Usamos attestation: 'none' para no enviar información del fabricante del dispositivo.
🚫

5. Terceros y tracking

UX Tools no utiliza ningún sistema de tracking, analytics ni telemetría. Concretamente:

  • Sin Google Analytics, Plausible, Mixpanel ni similares.
  • Sin cookies de seguimiento.
  • Sin píxeles de publicidad.
  • Sin Service Workers que capturen datos de uso.

La única conexión externa al cargar la aplicación es la fuente tipográfica desde fonts.bunny.net (alternativa de Bunny CDN a Google Fonts, con política de privacidad que no registra IPs de usuarios). Puedes consultarla en bunny.net/privacy.
