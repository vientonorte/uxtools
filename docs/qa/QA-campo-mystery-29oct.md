## P0 (bloquea uso en terreno / ética)
1. **Sin vínculo a la sesión OBS paralela.** El método dice MS en paralelo a cada sesión [D p11, P §4]; el formulario no pide código OBS-DD-MM-LUGAR-N. Agregar campo «Sesión OBS».
2. **Punto no usa códigos de lugar.** [D «Dónde se reparten los QR»: 12 puntos GEN, LLE, UCA, UCH, LHE, ECE, BAQ, ULA, LRE, PAJ, SPA, PMA] [P] exige códigos (BAQ, ULA, LRE, PAJ, SPA, PMA, LHE, ECE, MAT, PEN, NOS) y [A] los nuevos por lugar real (CMO, PZA, PBU, BEA, SIS, IRZ); «Punto» debe ser selector con esos códigos + «otro».
3. **No se puede borrar una ficha.** Datos de prueba/errores quedan en el SSOT; necesario para limpiar y para retirar algo sensible [G Ética].
4. **Evidencia sin control de anonimización.** [G] fotos solo de equipos/carteles, sin personas; [P §5] difuminar caras. Falta campo «Fotos/capturas (n° o enlace)» + casilla «caras difuminadas / sin personas» y aviso de no registrar nombres.
5. **Espera negativa se borra sin aviso.** Pérdida silenciosa de dato medido [G «Mide con el reloj»]. Validar y mostrar error.
